# リトル・ミュー診断

六つの二択から一枚の「心象肖像」を選び、回答とは独立した抽選で「王国来歴証」を授ける静的Webアプリです。

- 公開版: https://xiao1213-jpg.github.io/LMK3/
- モバイル: `?mode=mobile#start`
- 店頭端末: `?mode=store#start`

## 現行構成

公開ページは小さなES Modulesへ分割しています。入口で必要なのは約31KBのJavaScriptだけで、出生地・家系・診断文・QR生成は必要になる段階まで読み込みません。

- `index.html`: 現行版の入口
- `assets/app.js`: 画面遷移、保存、共有、遅延読込
- `assets/engine.js`: 六問の決定木、共有記録の復元
- `assets/world.js`: 回答と独立した王国来歴抽選
- `assets/diagnoses.js`: 24の診断文（保護対象）
- `assets/stories.js`: 24匹の物語（保護対象）
- `data/geography-v12.json`: 確定資料から転記した100出生地＋特殊出生地
- `assets/geography.js`: 検証済みデータから生成する公開用地理カタログ
- `assets/heritage.js`: 五爵位100家
- `tests/`: 決定木、地理、奇譚度、家系、表示文言の検査
- `docs/`: 診断設計と来歴抽選の仕様

## 結果の分離

心象肖像は六回答と診断用seedだけで必ず一枚に決まります。王国来歴証は別の抽選seedを用い、回答や肖像から独立しています。共有URLは両方のseedを保存するため、同じ一件簿を再現できます。旧六問リンクと旧九問リンクも互換表示します。

## 検証

```bash
npm test
```

出生地データを変更した場合は、先に公開用カタログを再生成します。

```bash
npm run build:geography
```

主な自動検査:

- 3入口 × 64回答 = 192経路を全数検査
- 24肖像へ各8経路で到達し、同率結果なし
- 通常100出生地の全到達、地方別件数、P分布（82/13/5）、特殊出生地の置換率を確認
- 30万回抽選で奇譚度分布と爵位非依存性を検査
- 五爵位100家の固有記録と復元性を検査
- 24診断文と24匹の物語本文を保護
