## 現在の完成仕様

- 15問＋「心が向くもの」が同点のときだけ追加質問
- 「心が向くもの」3分類
- 「受け継ぎ方」2分類
- 「美の置き場所」2分類
- 「喜びの味わい方」2分類
- 4 × 3 × 2＝24結果
- 各結果に診断本文、3要素の解説、回答の濃淡、近い結果、案内役の猫、似合うものを表示
- 24結果それぞれにSNS共有用URLを用意
- スマートフォン対応
- Google Analytics 4による匿名の利用状況集計

## 更新時の重要事項

現在の正本は、このリポジトリの **mainブランチ** です。

過去に作成した「LMK3 v1〜v3」などのZIPはバックアップであり、現在の公開版より古い内容です。古いZIPをそのまま再アップロードすると、診断文・レイアウト・案内役名・解析処理などの最新修正が上書きされます。

更新するときは、mainブランチ上の現在のファイルを基準に編集してください。

## GitHub Pages設定

公開URLが404になる場合だけ確認します。

1. リポジトリの **Settings**
2. 左側の **Pages**
3. **Source**：`Deploy from a branch`
4. **Branch**：`main`、フォルダ：`/(root)`
5. **Save**

通常、更新は1〜3分ほどで公開版へ反映されます。古い表示が残る場合は再読み込みするか、プライベートブラウズで確認します。

## 公開後の確認項目

- トップが「あなたはどの猫？」になっている
- 「リトル・ミューへ」から15問を開始できる
- 「ひとつ戻る」で直前の回答へ戻れる
- 同点時だけ追加質問が出る
- 24種類すべての結果へ到達できる
- 結果本文が案内役キャラクターの性格ではなく、診断分類に基づいている
- 「この結果をつくる3つの要素を見る」が開閉できる
- 案内役と「あなたに似合うもの」が表示される
- 「結果を共有する」「もう一度診断する」が動く
- スマートフォンで横方向にはみ出さない
- プライバシーページが開く

## アクセス解析

Google Analytics 4 測定ID：`G-FJ9LS51YKS`

記録するイベント：

- 診断開始：`diagnosis_start`
- 診断完了：`diagnosis_complete`
- 結果共有：`share`

同じ測定IDを使い続けるため、今後の集計は同じGA4プロパティへ蓄積されます。測定タグ設置前のアクセスは、後からさかのぼって記録されません。
