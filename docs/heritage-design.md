# 王国来歴証・奇譚度設計

## 二つの記録

- 心象肖像は、六つの回答だけから一枚に決まる診断結果。64回答 × 3入口の全192経路で、24枚へ8経路ずつ到達する。
- 王国来歴証は回答とは独立した来歴抽選。診断とは別の抽選seedから再生成するため、回答や肖像に来歴が左右されず、共有・再読込後も毛色、出生地、家、家伝品、奇譚度は変わらない。
- 招待状と一件簿では「六つの答えが選んだ肖像」「王国が授けた来歴」と書き分ける。回答一覧の振り返りは置かない。

## 出生地

- `assets/geography.js` は承認済み `リトルミュー_出生地100_幻想地誌_v6_再統合版.xlsx` から機械生成する。
- 100出生地、7地域。神秘点は P0=60、P1=30、P2=10。
- P0 は幻想的な日常景観、P1 は土地固有の言い伝え、P2 は聖地・境界・王国の深層へ直接触れる土地。
- ベルグレイブ・ガーデンズやセント・アルバンの格式・知名度は、神秘点を増やさない。
- UIでは地名に加え、「ホワイトクリフ地方」などの地理区分、地方像、土地に残る話を順に表示する。

## 王国奇譚度

星は身分・富・職業・住所の格式・爵位・全組合せの出現確率を表さない。次の四要素だけを個別に見る。

1. 毛色 C：出現率 8%以上=0、3%以上=1、0.5%以上=2、0.5%未満=3。
2. 土地 P：出生地資料の神秘点 0–2をそのまま使用。
3. 家の習わし F：日常=0、古い伝承との接点=1、王国の深層へ続く記憶=2。
4. 家伝品 I：日用品=0、記憶を受け継ぐ品=1、奇譚そのものに触れる品=2。

土地タグと、家・家伝品のタグが一致した場合だけ「縁」R=1を加える。タグは天象・季節・聖史・自然・導き・境界・祝福・記憶の8種。

`S = C + P + min(3, F + I) + R`

| 表示 | 条件 | 意味 |
|---|---|---|
| ★ | S 0–2 | 王国の小さな物語 |
| ★★ | S 3–4 | 不思議の気配 |
| ★★★ | S 5以上、ただし四要素すべては揃わない | 古い伝承との縁 |
| ★★★★ | S 6以上、かつ C/P/F/I の全てが1以上 | 王国に残る奇譚 |

珍しい毛色一つだけでは二つ星まで。四つ星には四つの独立したしるしが必須で、爵位だけでは一つも増えない。全組合せの出現確率が低い場合は、星と分けて「とても珍しい組み合わせ」とだけ記す。

## 爵位家

- 五爵位 × 20家 = 100の家印・家の情景・家伝品を個別に収録する。
- 爵位ごとの紙色、家印、装飾の密度は、家の華やかさを演出する。これは奇譚度と別の当たりである。
- 奇譚メタデータは全爵位で同じ分布に固定する。家の習わしは 0/1/2 が 6/10/4家、家伝品は 0/1/2 が 8/8/4家。公爵だから高得点、男爵だから低得点という規則はない。
- 家の選択は既存seedの決定的ハッシュ。来歴抽選の乱数列を追加消費せず、復元結果を変えない。

## 検証基準

- 100出生地が実際のseed群で全て到達する。
- 30万抽選で星の目安は、★34–48%、★★34–48%、★★★10–18%、★★★★3–7%。
- 四つ星は全件、C/P/F/Iの四要素を持つ。
- ベルグレイブ・ガーデンズはP0のため、住所だけで星が上がらない。
- 公爵・侯爵・伯爵・子爵・男爵の平均星差は0.15未満、爵位家／非爵位家の平均差は0.25未満。
- 24の診断文と、ユーザー支給の24匹の物語本文は変更しない。
